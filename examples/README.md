# 示例：从一段剧本到分镜工程

下面是一段很短的原创剧本，可以直接拿来试。装好 `rooyun` 插件（或手动装好 skill）并登录后，把剧本和提示词一起发给 Agent。

## 剧本：《末班地铁》

```
第 1 场　地铁车厢　夜
末班地铁，车厢里只剩林夏一个人。她抱着一摞设计稿，靠着车窗打瞌睡。
广播：「本次列车终点站，南湖公园。」
林夏猛地惊醒，发现对面坐着一个穿旧式校服的少年，正盯着她手里最上面那张稿子。
少年：「这座桥，你画错了。」
林夏低头看稿子，再抬头时，对面的座位空了。车窗外，一座她从没见过的石桥一闪而过。
```

## 完整版（`rooyun`）提示词

```
用 RooYun 把下面这段剧本搭成画布工程：拆出角色、场景和道具，再按剧本出分镜，
画风用国漫厚涂，竖屏 9:16。先把分镜计划和生成报价给我看，我确认后再生成。

<粘贴上面的剧本>
```

Agent 会依次：建项目 → 用平台 LLM 拆出角色（林夏、少年）、场景（地铁车厢、石桥）、道具（设计稿）并落成卡片 → 派生分镜视频卡 → 报价并等你确认 → 生成定妆照、分镜图和视频 → 把画布链接交给你，你可以打开浏览器接着改。

## 精简版（`rooyun-cli`）提示词

```
用 RooYun 生成一张图：末班地铁车厢，深夜，女孩抱着设计稿靠窗打瞌睡，
对面坐着穿旧式校服的少年，国漫厚涂，9:16。先报价。
```

精简版会把你的提示词原样提交，不会先建角色板，也不要求按固定顺序走。

## 费用

生成图片、视频和配音会消耗 RooYun 积分，具体以生成前的报价为准。用平台 LLM 拆剧本会按用量扣少量积分；搭画布、读选题情报不扣积分。计费方式见 [价格说明](https://www.rooyun.com/learn/pricing?utm_source=github&utm_medium=example)。
